API Gateway & Routing Topology

Reactive reverse proxy ingress running on Port 8080. Enforces JWT authentication, rate limiting, and discovery routing.

🌐 Gateway Ingress Specification

  • Port: 8080 (Reactive Netty Engine)
  • Discovery Locator: Enabled (Eureka lower-case service-id resolution)
  • Security Engine: JJWT 0.11.5 + HMAC-SHA256 Stateless Claims
  • Resilience: Reactive CircuitBreakers via Resilience4j
  • Distributed Tracing: Micrometer Tracing Brave Bridge + W3C propagation

🔒 Security & RBAC Enforcement

  • Public Paths: /api/auth/**, /api/products (GET), /api/system/**, /actuator/**
  • Customer Scope: /api/orders (POST), /api/orders/customer/{id}
  • Admin Scope: /api/products (POST/PUT/DELETE), /api/inventory/**, /api/orders (GET all)
  • Token Claims: X-User-Id, X-User-Roles, X-Correlation-Id
